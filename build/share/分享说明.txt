  DS鲸鱼娘桌宠 —— 分享说明 / 许可与署名
══════════════════════════════════════════════════════════════════

这是一个把「DS鲸鱼娘」Live2D 模型做成桌面宠物的免费小程序。
可以自由分享给他人,但请先读完下面几段(尤其是「许可」与「对话怎么配」)。

──────────────────────────────────────────────────────────────────
一、怎么用
──────────────────────────────────────────────────────────────────
1. 双击 DSWhalePet.exe 即可(免安装;exe 文件名请保持纯 ASCII,改名成中文会启动崩溃)
2. 鼠标移到鲸鱼娘旁边 → 下方自动弹出输入框;左键拖动可移动位置(位置会记住)
3. 左键点一下 = 戳它一下:它会说一句 + 换个表情回应你(需要先配好对话,见第二节;没配时点击不做事)
   右键 = 动作菜单(44 个表情 / 7 个动画 / 设置 / 置顶 / 穿透 / 开机自启)
4. 快捷键:Ctrl+Alt+W 显示隐藏,Ctrl+Alt+E 聊天
5. 点击穿透:鼠标不在模型身上时,点击会落到桌面,不会挡你干活

──────────────────────────────────────────────────────────────────
二、对话功能怎么配(重要:每台机器各自配)
──────────────────────────────────────────────────────────────────
本程序【不附带任何 API Key】,也不会使用别人的 Key。想用对话,三种方式任选:

【方式 1】填自己的 API Key(推荐)
  右键桌宠 →「设置…」→「对话」→ 服务商选 DeepSeek 或 OpenAI → 填入自己的 Key → 保存
  (费用由 Key 持有人自己承担;DeepSeek/OpenAI 都是按用量计费的付费服务)

【方式 2】用本地模型(Ollama,完全免费、可离线)
  1) 先装 Ollama 并拉一个模型,例如:ollama pull qwen2.5:7b
  2) 设置 →「对话」→ 服务商选「Ollama 本地」→ 保存(地址默认 127.0.0.1:11434,无需 Key)
  3) 点「测试对话」确认能通

【方式 3】不配,当纯桌宠用
  完全不配置也能正常使用:表情、动画、拖动、穿透、快捷键、托盘都不受影响,
  只是不能聊天(程序不会报错打扰你)。

其它:也支持任何 OpenAI 兼容的中转/自建服务 —— 在设置里填「接口地址 + 模型名」即可。
