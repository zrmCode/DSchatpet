# assets 目录说明

```
assets/
├── model/          ← Live2D 模型放这里(**不随仓库分发**,见下)
├── 许可/            ← 模型作者的原始条款与按键表(随仓库保留,署名用)
└── README.md       ← 本文件
```

也就是本项目的 **GitHub Release 免安装压缩包** —— 一起提供。

> 想省事就直接下载 Release 里的压缩包,解压双击即可,模型已在内。
> 想从源码跑,请按下面任一种方式拿到模型。

## 怎么拿到模型

**方式 1:从 Release 压缩包里取**
下载本项目的 Release 免安装 zip,把其中的 `_internal/assets/model/` 整个目录
复制到本仓库的 `assets/model/`。

**方式 2:联系作者**
到 B站找 @氵六青 或加交流群 645169617,按作者说明获取(记得遵守"禁止出售")。
拿到后把目录放到 `assets/model/`。

**方式 3:换一个你自己的模型**
本程序对模型没有硬编码:任何包含 `*.model3.json` 的 Live2D 模型目录都能跑,
用 `--model-dir <目录>` 指定即可。表情/动作菜单来自目录里的 `*.vtube.json`
(没有这个文件就只是菜单里没有动作,渲染与对话都正常)。

## 期望的目录结构(以本模型为例)

```
assets/model/
├── c_0120.model3.json        ← 入口(必须;程序按 *.model3.json 查找)
├── c_0120.moc3               ← 模型本体
├── c_0120.physics3.json      ← 物理演算(头发/尾巴摆动)
├── c_0120.cdi3.json          ← 参数/部件显示名
├── c_0120.vtube.json         ← 表情与动作清单(右键菜单的 52 项来源)
├── c_0120.2048/              ← 贴图(2 张)
├── motions/                  ← 7 个动作(*.motion3.json)
└── *.exp3.json               ← 44 个表情
```

缺模型时程序不会静默闪退:会弹一个原生消息框告诉你该放到哪个路径,
并可以直接帮你打开那个目录。命令行下则打印到 stderr 并以退出码 2 结束。
